# Raul Bayramov — CV & Proje Kataloğu

Modern, minimalist ve mobil uyumlu tek sayfalı portföy sitesi.

## Teknolojiler

- React + Vite
- Tailwind CSS v4
- Lucide React

## Başlatma

```bash
npm install
npm run dev
```

## İçerik güncelleme

Tüm kişisel bilgiler, yetkinlikler ve projeler `src/data/portfolioData.js` dosyasındadır. Yeni proje veya Drive linki eklemek için yalnızca bu dosyayı düzenlemeniz yeterlidir.
